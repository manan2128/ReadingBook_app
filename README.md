# ReadingBook_app-25BCON1092

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-n27xu5pp)
This app is for tracking no. of books read.

## Live application

[Open the reading list](https://manan-reading-list.vercel.app)

Add book titles, change their status between Want to Read, Reading, and Finished, and filter the list. Books persist in this browser's localStorage and do not synchronize between devices.

## Local setup

With Node.js installed, run `npm install` followed by `npm run dev`. Build with `npm run build`. Vercel uses the Vite framework and the `dist` output directory.
